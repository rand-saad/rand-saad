## 🌾 SUNBULA | سُنبلة

### AI-Powered Agriculture for Iraq

<img width="100%" src="https://capsule-render.vercel.app/api?type=rect&color=0:071A2E,100:063D55&height=110&text=SMART%20AGRICULTURE&fontSize=27&fontColor=00E5FF&fontAlignY=50"/>

</div>

**Sunbula** is an Arabic-first, offline-capable agricultural AI application designed to empower Iraqi farmers with accessible artificial intelligence.

### Core Features

- 🌱 **Plant Disease Diagnosis:** On-device AI-powered plant disease detection.
- 🤖 **Abu Sunbula:** An Arabic agronomy AI assistant — أبو سُنبلة.
- 📱 **Offline-First:** Designed to work without continuous internet access.
- 🇮🇶 **Local Impact:** Agricultural intelligence designed for Iraqi farmers.
